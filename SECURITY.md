# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
| < 1     | ❌        |

## Reporting a Vulnerability

If you find a security vulnerability in the RL embedded scripting engine, please report it by
opening an issue on this repository or contacting a maintainer directly via GitHub.

I'll respond as soon as possible. If the vulnerability is valid I'll work on a fix and credit you
in the release notes.
